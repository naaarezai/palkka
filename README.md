# AKT Palkanlaskenta

Kuljetusalan TES-pohjainen palkanlaskuri (2025-2026).

## Ominaisuudet

- Vuoron alku/loppu ja tauot
- AKT TES -mukaiset lisät (ilta, yö, sunnuntai, lauantai)
- Kokemuspohjainen tuntipalkka (palveluvuodet)
- Tallenna vuorot Supabase-pilveen
- Kirjautuminen sähköpostilla

## Kehitys

```bash
npm install
npm run dev
```

## Ympäristömuuttujat

Luo tiedosto `.env.local`:

```
NEXT_PUBLIC_SUPABASE_URL=sinun_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=sinun_key
```
